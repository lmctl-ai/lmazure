# Host flag cutover

Only --lmcode, --lmcode-schema and --lmcode-signatures are accepted; no retired
aliases remain. DSLB magic, internal .dslb paths, mock/live guards and diagnostics
are unchanged. The normal gate checks old-option refusal, exact schema bytes
against the archived original host's SHA-256, exact host-signature parity with
the source compiler, and the new loader route. A deliberately wrong schema hash
was observed to fail the byte assertion.

The SDK archive is pinned at C# main 931e0ed and regenerated by sync-sdk.py,
including the existing allocation checkpoint seam (not a manual vendor edit).
The complete managed test.sh passes with .NET 10.0.402 and a mono-main compiler
using the renamed protocol. Thirteen additional actual bytecode execution checks
pass through the managed host: fake inventories, ownership cleanup, cost caps,
invalid handles, dry-run, denied live operations and runaway allocation.

The 72 gallery assets/configurations are checked, but gallery execution requires
updated external draw/plot hosts and remains the existing optional gate. No
Azure call, release, global toolchain replacement or alias fallback was used.
